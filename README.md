# Чистка компьютера для Windows

Небольшое графическое приложение для управления установленными программами и освобождения места на диске. Основной сценарий — найти программу, выбрать одну или несколько и запустить их штатные деинсталляторы.

## Скачать и запустить

Запустите **[Чистка-компьютера.exe](Чистка-компьютера.exe)**. Это единый exe-файл; дополнительные файлы для запуска не нужны. Приложение рассчитано на Windows x64 с Windows PowerShell и Windows Forms.

## Возможности

- Каталог обычных программ из реестра Windows и приложений Microsoft Store текущего пользователя.
- Поиск по названию, издателю и версии; фильтр по области установки.
- Сведения об издателе, версии, папке установки и сохранённой установщиком оценке размера.
- Выбор нескольких программ и последовательный запуск зарегистрированных штатных деинсталляторов после подтверждения.
- Переход к странице «Установленные приложения» Windows для пакетов Store и записей без обычной команды удаления.
- Анализ больших папок на выбранном диске, оценка последнего доступа и рекомендации по их содержимому.
- Очистка старых файлов из известных временных папок и корзины.

## Сборка из исходников

Исходный интерфейс находится в `Cleaner.ps1`. Для сборки нужен Windows PowerShell 5.1 и модуль [PS2EXE](https://github.com/MScholtes/PS2EXE):

```powershell
Install-Module ps2exe -Scope CurrentUser
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Скрипт `Build.ps1` создаёт `Чистка-компьютера.exe` в этой же папке. Параметры сборки: x64, графический режим без консольного окна, версия 1.0.0.0.

## Ограничения

- Деинсталляторы запускаются по командам, зарегистрированным самой программой. Для Store и неподдерживаемых команд используется Windows.
- Программа не удаляет папки приложений и записи реестра вручную; принудительное удаление и автоматическая очистка остатков не входят в эту версию.
- Размер приложения показывается, только если его сохранил установщик. Оценка последнего доступа к файлам зависит от метаданных Windows и может быть неточной.
- Для обычных больших папок приложение показывает рекомендации и не удаляет их автоматически.

Каталог программы и очистка работают локально; приложение не отправляет данные на сервер.
